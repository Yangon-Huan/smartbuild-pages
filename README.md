# 智能建造本地演示软件

双击 `启动软件.bat` 打开首页。首页底部四个入口进入槽道检测、槽道外观检测、平整度检测和现场采集。右上角依次为切换用户、设置、退出软件。

编辑 `config.md` 后保存，页面会自动热加载。首页文字和图片路径在 `home` 区块；用户、设置、退出弹窗文字分别在 `login`、`settings`、`shutdown` 区块。账号是本地演示账号，默认口令见配置文件。

详情见 `开发说明.md`；布局见 `页面示意图.svg`。

现场采集页的文字、图片、采集时间、三个工作区初始信息在 `config.md` 的 `capture_ui` 区块修改。点击“开始采集”后当前工作区由未采集变为采集完成，高清成像图片随之显示。前后视角暂用参考截图中的画面。

首页点击“槽道检测”进入数据分析页。任务列表、列名、按钮及提示文字均在 `config.md` 的 `analysis` 区块设置；用 `tasks` 增减任务，页面自动更新总数和分页。搜索按任务名称筛选；点击任务行的“分析”进入新的数据分析详情页。删除仅影响当前打开的软件会话，刷新页面可从配置重新载入。

数据分析详情页的文字、卡片、数量、测量列和预设结果在 `config.md` 的 `analysis_detail` 区块设置。点击“单滑槽分析”可选择本地文件，选择后运行预设分析；“一键分析”批量更新演示状态；“导出测量数据”下载当前卡片数据 CSV。

更新程序脚本后，已打开的浏览器页需要重新载入代码；按 `Ctrl+F5`，或重新双击 `启动软件.bat` 打开带新地址参数的页面。`config.md` 的内容仍可直接保存热加载。静态文件响应已设为不缓存。

单滑槽分析现在可选择本地 PLY、XYZ、PTS、TXT 或 CSV 点云。选择后，左侧可用鼠标旋转、缩放和平移预览，右侧立即显示 `config.md` 中的六项预设参数；点击“确定”保存本次演示结果，“取消”撤销，“清空”重置预览。“几何参数”切换预览标注。提供的 `data/隧道点云01.ply` 可直接选用。点云只在浏览器本地读取，不上传。

首页点击“槽道外观检测”进入独立的“数据分析 / 图像分析”页面。左侧三个工作区可切换和编辑；右侧显示本地槽道高清成像图片与缺陷字典库。点击“开始检测”后，当前工作区变为检测完成，并展示 `config.md` 的 `image_analysis` 区块中预设的锈蚀、脱落面积与严重程度。所有文字、图片路径和预设值保存配置后热加载。

点云预览已改用分段抽样读取二进制 PLY；随包约 93 MB 的 PLY 默认仅读取约 2 MB 片段并绘制最多 4 万点。预览显示进度，30 秒仍未读完会提示超时，可取消并重选文件。

图像分析页标题使用 `config.md` 中 `image_analysis.heading_parent`、`heading_separator`、`heading_current` 组成的面包屑。页面整体固定在浏览器窗口内；只有左侧工作区列表可用鼠标滚轮或滚动条上下查看。

随包的 `data/隧道点云01.ply` 有同源的 520 KB 抽样预览文件。选择文件名及大小匹配的点云时，页面优先读取预览文件，快速显示原点云的约 4 万个实际点；其它点云继续使用浏览器本地分段读取。文件选择控件在页面重绘时保留。修改程序文件后请按 `Ctrl+F5` 更新页面。

确认本地点云后，点击“导出测量数据”，软件会更新 `data/导出数据/导出测量数据.xlsx` 并打开测量表页。每个点云文件占一行；同名点云再次导出会覆盖原行，不同点云会追加。工作表首行显示点云记录数，后面列出点云文件名、工作区及六项测量值。表格页右上按钮可再次更新。数值来自 `config.md` 的预设演示数据，Excel 中标注数据来源。更新 `server.py` 后需关闭并重新启动软件服务。

点击“一键分析”后，在文件夹选择窗口选择 `data/导出数据`。软件读取所选文件夹中的 Excel 测量记录，按点云文件名展示六项已导出测量结果；按钮显示绿色“分析中”及图标，至少 2 秒后显示结果表。匹配到测量记录的“滑槽扭转、变形情况”按当前演示要求直接显示“合格”，Excel 中每个点云文件对应一行。此状态是演示显示，不是按工程阈值计算的判定。更新 `server.py` 后需重启软件服务。
